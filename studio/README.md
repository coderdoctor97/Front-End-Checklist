# Front-End Checklist Studio

Standalone Next.js app for the Front-End Checklist: interactive sidebar, client-side AI providers, GitHub repo context, and coding-agent prompt generation.

## Run locally

```bash
cd studio
npm install
npm run dev
```

Open http://localhost:3000

## MCP links included in generated prompts

- Content Checklist MCP: https://mcp.frontendchecklist.io
- GitHub MCP: https://link.mcpmarket.com/earningbuddyv/github-chat/mcp
